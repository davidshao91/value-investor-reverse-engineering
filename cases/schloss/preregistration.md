# 施洛斯跌落蓝筹 — 预注册

锁定时间：2026-10-20 08:15（上海），写的时候还没有覆盖率、收益和回撤。当时只看过数据文件的清单和日期范围。及格线的数字门槛没有改。

公开时只改措辞。规则、30 个名额、48 个月、退市三档、M3/M4 的增量门槛，保持原样。

这条规则押的是大盘股被过度抛售之后会回归，不是利润增长可预测。它是施洛斯用过的一类，不代表其业绩的主要来源。

## 数据

- 成分：标普 500 逐日成分快照。月末取当天或之前最近一天的名单。
- 价格：含退市的标普调整收盘价（2000–2024）为主；2000 年以前和 2025 年以后用另一套复权价，按重叠日期的收益率相关性拼接。相关性低于 0.9 则不拼。排除四个已知对不上的代码：PBG、SLR、CBE、FBF（行情审计，不是持仓名单）。
- 信号日前三年内，若出现单日涨幅超过 150% 或跌幅超过 75%，当月不入选。
- 基准：SPY；作者自己的保守基准组合（不公开，可选）；案例内计算的成分等权。现金利息用 13 周国库券收益率 / 252。
- 覆盖率：每年、在成分股当月，当天有价且至少有三年历史的比例。先报覆盖率，再报业绩。

## 规则

共同约定：月末信号，次一交易日收盘成交（用当日收盘近似，滞后一天）。30 个名额。每个新仓分配 min(净值/30, 现金)。持仓不再平衡。候选多于空位时，按距离五年高点的跌幅从深到浅排序。已持有的不重复开仓。退出后 6 个月内不买回同一名字。离开指数不卖。

- **M2-v1：** 价格 ≤ 1.25 × 过去 756 个交易日最低收盘，且价格 ≤ 0.60 × 过去 1260 个交易日最高收盘。历史不足 1260 日时用全部可得历史，但至少 756 日。退出：价格 ≥ 建仓日前 756 日收盘中位数（建仓时固定），或满 48 个月。
- M2-v1b：只要求比五年高点至少低 40%。不作主判定。
- **C3L：** 只要求价格 ≤ 1.25 × 三年低点。排序改为离三年低点更近的优先。
- **M2-v2（2009 年以后的财报）：** v1 的价格条件，加上市净率处于自身至少 20 个季度（最多 40 个季度）的最低 20%，并且负债/权益 < 1。财报滞后 90 天可用。权益 ≤ 0 不入选。代码对照用 SEC 当前的公司–代码表，覆盖率必须报告。退出：市净率回到自身历史中位数，或满 48 个月。
- **M3：** 名额预算在开仓时预留。首笔三分之一；价格跌到上一笔的 0.85 倍时再加三分之一，最多三笔。对照是同一规则一次买完。
- **M4：** 只在 M2-v1 一次买完上做三个变体。X1 在均价 1.5 / 2 / 3 倍各卖三分之一，48 个月清掉剩余。X2 只按 48 个月卖。X3 上涨 50% 全部卖出，48 个月封顶。

## 退市

价格序列在计划退出之前结束：

- **D0（主）：** 按最后收盘价卖出。
- **D2：** 同 D0，卖出所得改跟 SPY，直到原本最晚的退出日。
- **D1：** 该仓位归零。另报一档：只有最后价低于序列结束前一年最高价的 30% 时才归零。

没有价格的成分股不能被选中，不用虚拟行情去填。

## 判定

- 窗口平均覆盖率 < 70% → 数据 blocker。要到前向观察，D0、D2、D1 三档都得过线。
- 覆盖率 ≥ 70%，但没有标准退市收益 → 最高前向观察。D0 不过 → **放弃**。
- 主规则过线但 Calmar 不高于 C3L → 写成「低位反转，施洛斯的附加条件没有增量」。
- M3：相对一次买完，Calmar 提高至少 0.02，且回撤不更深 → 「分批买有增量」。
- M4：任一变体相对主规则的 Calmar 差至少 +0.05 才算有增量。三个变体不因为「有一个碰巧好」而放宽门槛。
- v2 无法检验 2000 和 2008 起点 → 最高前向观察。
