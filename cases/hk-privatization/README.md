# 港股私有化

**结论：数据 blocker。** 两条都停在这里。P1 是「私有化已经公告，买入，持有到完成」。P2 是「净现金多、控股股东持股高的公司，会不会更常被私有化」。2019 年以后能算的一段诊断，也没有过及格线。下面的完成率和单笔期望值是附带统计，不是一套通过的策略。

这不是巴菲特合伙年代业绩的复现。它只是早年「便宜，并且出现私有化」那条规则，在美股免费行情盖不住退市公司之后，换到港股试的一条解锁路径。锁定文本在 [preregistration.md](preregistration.md)，写于 2026-10-20 08:15（上海），当时还没有这批价格和收益。数字表在 [备忘录](hk_privatization_case_2026-10-20.md)。

## 数据为什么断了

两件事叠在一起，免费数据就接不上。

**代码会被重新使用。** 公司私有化退市之后，这个号码会发给下一家公司。新浪、雅虎这类免费行情只保留现在用这个号码的那一家。旧公司的价格历史被盖掉。Webb-site 上 2001 年到 2025 年上半年、原因记为私有化的完成案有 **246** 宗。2001–2014 年每年能对上旧价格的比例是 **0%**。2008 年以后整段的价格覆盖是 **58%**，2000 年以后整段是 **46%**，都低于事先写的 70%。2008 年起的早年三年窗口也低于 50%（2008–2014 这几窗是 0）。两条 blocker 条件都触发了。按锁定规则，P1 到此为止，后面的回测只作诊断。

**港交所的标题检索不给出已退市发行人的公告。** 默认检索只落到还在上市的公司。已经退市的那一家，公告不在结果里。所以完成案的公告日、要约价，不能从这套检索补齐；失败案也只能从仍上市的目标里整理。本轮这样整理出 **31** 宗，其中有价格的 24 宗。失败名单因此偏少，完成率偏高。

P2 还缺另一块：退市公司在某个建仓日之前已经公布的净现金，以及当时的控股比例。没有时点数据，就不知道「净现金高、控股高」是不是比别的公司更容易被私有化。能报的只有无条件基础率：2019–2025 年大约每年 10–28 宗，相对大约 2,600 家上市公司，大约 **0.5%–1% / 年**。提升倍数无法检验。P2 同样是数据 blocker。

## 规则

公开基准是盈富基金 **2800.HK** 的调整收盘价。作者自己的保守基准组合（不公开）只作可选对照，文件不在仓库里。及格线的数字门槛沿用[仓库首页](../../README.md)，没有因结果改动。

| | 内容 |
|---|---|
| **P1（主规则）** | 规则 3.5 确实意向公告之后的第一个收盘价买入。价差 = 要约价 / 价格 − 1，至少 **5%** 才买。持有到完成（注销后大约 10 个交易日收到现金）或失败后的下一个收盘价。每个事件用当时净值的 10%，同时最多 10 笔。现金收益记 0。主成本是成交额的 30bp |
| P2 | 非金融；净现金 / 市值 ≥ 0.5，并且市净率 ≤ 0.7；控股股东持股 ≥ 50%。看未来 1 年和 3 年内出现私有化公告的比例，是不是至少达到全体公司的 2 倍 |

价差为 0 的版本、以及每笔 25% 的版本，都是诊断，不能把主规则救回来。完成案在 Webb 名单里没有公告日。脚本用退市前的价格路径反推一个跳升日，这一步用到了最终价格，会截掉「价差很宽、最后仍然完成」的那一截。因此诊断里的 5% 价差也是前视的，只作参考。

## 附带的单笔统计

有价格的子样本里：完成 99 宗，失败 24 宗。

| | 中位数 |
|---|---|
| 完成，从入场到结束 | **+8.3%**，大约 **124** 天 |
| 失败，从入场到卖出 | **−21.5%**（2019–2025 年为 −24%） |
| 失败之后相对公告前价格 | +1.5% |

完成率按 2019 年以后、能标上日期的完成案，对上有价格的失败案，大约 **88%–90%**。失败名单缺了已退市发行人，这个比例偏高。

单笔可以粗算成：完成的机会大约九成，失败的机会大约一成，所以每宗期望大约 **0.9 × 价差 − 0.1 × 跌回去的亏损**。用上面两个中位数代入：0.9 × 8.3% − 0.1 × 21.5% ≈ **每宗 +5.3%**，占用大约四个月。这是给已经公告的个案看的算法。每年只有十几到二十几宗，按 10% 的仓位，组合大部分时间是现金，诊断组合的年化只有大约 3%–6%。

## 2019 年以后的诊断

窗口 2019-01-02 → 2026-09-30。这段价格覆盖大约 **73%**（130 宗里有价格的占七成出头），仍然只作诊断：起点不是 2008 年，覆盖率也是挑了数据还在的年份。同窗口 2800.HK 年化 3.2%、最大回撤 −49.4%、Calmar 0.064。作者自己的保守基准组合（不公开）在同一窗口的汇总是年化 15.7%、最大回撤 −19.4%、Calmar 0.81。

六档相对 2800、去掉超额最好的三年之后，最高是 +0.03，其余为负。相对作者自己的保守基准组合（不公开），六档都是负的。主规则那一档两边都不过。对 2800 的正差，大部分来自 2021–2023 年港股下跌时这套规则仓位很轻；2024–2025 年港股反弹时，它只有大约 +2.6% 和 −1.3%。2026 年是 0，因为完成案名单收到 2025 年 6 月。

所以即使不看覆盖率，这段诊断也过不了及格线。覆盖率本身已经触发数据 blocker，诊断不能把它升级成前向观察，也不能改写成一套通过的策略。

## 局限

- 2015 年以前的完成案几乎没有价格。2008 年这个预设起点无法检验。
- 完成案的入场日用最终价格反推，左尾被截掉。5% 价差那一档是前视。
- 终值用最后交易日的收盘价代替要约价，略偏保守。股息和到账日没有逐笔复原，完成案统一再加 14 个自然日。
- 失败名单只来自仍上市的目标，完成率偏高，失败时的亏损可能偏小。
- 没有分开预条件要约、H 股吸收合并、要约人中途加价。
- P2 没有退市公司的时点财务和控股比例。

## 怎么重跑

行情缓存放在 `data/hk_privatization/`，不进仓库。小名单在 `ref/`。可选对照沿用 `data/private/author_benchmark.csv`（列：`date`, `nav`）。不提供这个文件时，脚本只和 2800.HK 比较，也不会把该组合的净值写进 `out/`。

```bash
export VIRE_DATA=/path/to/data   # 可选，默认是仓库下的 data/
python cases/hk-privatization/code/h01_titles.py 2019 2019
python cases/hk-privatization/code/h04_cov.py
python cases/hk-privatization/code/h07_bt.py
```

`h01` 拉港交所标题，`h01b` 是把检索类别改成非活跃发行人的同一次尝试，`h02` 过滤标题，`h03_inactive` 拉非活跃代码，`h03_px` 用 akshare 下日线（需要另装 akshare），`h05` 归并失败片段，`h06` 生成事件表。数据清单见 [docs/data.md](../../docs/data.md)。
