# 案例

第一批已经做完。点进目录先看结论，再看做法和数字。

| 案例 | 规则（白话） | 结论 |
|---|---|---|
| [lynch](lynch/) | 利润在增长、PEG 小于 1、负债不高的股票，每年换一次 | **放弃** |
| [greenblatt](greenblatt/) | 现金并购：价差至少 5% 才买；分拆：分拆完成后持有 12 个月 | 并购套利 **放弃**；分拆 **数据 blocker** |
| [buffett](buffett/) | 净现金比市值还多，并且过去一年真的在回购或出现私有化 | **放弃** |
| [schloss](schloss/) | 标普里跌到多年低点、又从五年高点跌掉四成的股票 | **放弃**（市净率版本是数据 blocker） |
| [hk-privatization](hk-privatization/) | 私有化公告之后买入并持有到完成；另看净现金高、控股高的公司会不会更常被私有化 | **数据 blocker**（2019 年以后的诊断也不过线） |

及格线写在[仓库首页](../README.md)。阶段结论在 [docs/batch-1-summary.md](../docs/batch-1-summary.md)。每个案例的 `preregistration.md` 是出结果之前锁定的规则，公开时只改了措辞，没有改数字门槛。

`out/` 里的小表是当时跑出来的结果。列名里的 `author` 是作者自己的保守基准组合（不公开）在同一窗口上的打分对照：有的列是它的汇总年化、最大回撤和 Calmar，有的列是规则相对它的差额。港股案例的 `p1_bars.csv` 用 `bench` 一列区分 `2800` 和 `author`，同样只有汇总分数。不是股票代码。该组合的成分，以及它的逐月、逐年净值，没有放进这些表。不在本机提供可选基准文件就重跑时，新结果里不会再计算这些列。
