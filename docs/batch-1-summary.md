# 第一批收口

**六套规则都没有在锁定及格线下打败基准。** 数据够做完检验的，结论是放弃。免费数据缺关键一块的，结论是数据 blocker。没有一套进入前向观察，也没有一套到备忘录门槛。及格线写于 2026-10-19，之后没有因结果改动。数字和做法在各案例目录里。

| 规则 | 结论 | 相对基准 |
|---|---|---|
| [林奇：用过去三年利润增长算 PEG](../cases/lynch/) | 放弃 | 2012–2026，Calmar 0.43，低于 SPY 的 0.62，也低于作者自己的保守基准组合（不公开） |
| [格林布拉特：现金并购，价差至少 5%](../cases/greenblatt/) | 放弃 | 核查后年化约 1.1%，Calmar 0.38。单笔价差是真的，组合大部分时间是现金 |
| [格林布拉特：分拆完成后持有](../cases/greenblatt/) | 数据 blocker | 免费行情只覆盖大约一半已完成的分拆。缺价格的那一档按 −100% 处理时不过线 |
| [巴菲特合伙年代：便宜，并且有催化剂](../cases/buffett/) | 放弃 | 2009 年以后篮子能组出来，Calmar 0.33，低于 SPY，也低于「同样便宜、没有催化剂」的对照 |
| [施洛斯：标普里跌到多年低点、又从高点跌掉四成](../cases/schloss/) | 放弃 | 2000–2026 年化约 6.5%，最深跌约 61%，不如直接持有标普。市净率再滤一遍时，财报覆盖不够，那一档是数据 blocker |
| [港股私有化：公告后买入；以及净现金加高控股](../cases/hk-privatization/) | 数据 blocker | P1 在 2008 年以后只有 58% 的完成案有价格，2001–2014 年是 0%。P2 没有时点财务和控股比例。2019 年以后的诊断也没有过线 |

公开对照是 SPY、标普成分等权，以及港股案例里的盈富基金 2800.HK。作者自己的保守基准组合（不公开）只参加打分，成分和净值序列不在仓库里。

## 这说明什么

能写成规则、并且免费数据够得着的那一截，没有复现出这些记录里的超额。记录里站得住的那部分，更像当时一笔一笔的判断：读哪一份文件、哪一宗价差值得做、哪一家公司的故事成立。这些步骤没有被收成「另一个人可以独立执行」的买卖公式。

规模会把超额的比率摊薄。麦哲伦基金 1978–1981 年还很小、并且不向新投资者开放时，相对标普的领先大约 28.7 个百分点；1985–1989 年规模已经到数十亿美元，领先大约 3.8 个百分点。AQR 把 1977–1990 年的月度收益扣掉市场、市值和动量之后，剩下大约每年 8.3 个百分点，价值因子只解释其中大约 0.6 个百分点。那个残差不在「市盈率除以过去的利润增速」这条公式里。

## 这不能说明什么

这批结果不能说明这些投资人没有优势。它只覆盖了能事先写成规则的那一截。逛商场、拜访管理层、在一份厚文件里决定做不做，都写在各案例的局限里，没有拿去回测。

它也不能说明「价格对上价值」这个框架无效。本仓库把成长股、分拆、并购价差都留在这个框架里。分得开的是另一件事：哪一段能打分，哪一段只能留在当时的判断里。

免费数据还有两道硬边界。开源 XBRL 从 2009 年前后才比较完整，所以林奇和巴菲特这两条，2000 年和 2008 年的起点事先就知道无法检验。免费行情通常只有今天还在用的代码，后来被收购、私有化或破产的公司正好缺席。缺的往往是结果最极端的名字。分拆文献里，长期超额有很大一块来自后来被收购的那一批；免费价格丢掉的就是这一批。

## 还开着的数据缺口

| 缺口 | 现在缺什么 | 补上什么才能重开 |
|---|---|---|
| 分拆 | 退市之后 12–24 个月的价格。2009 年以后覆盖大约 52% | 含退市序列的行情，例如 CRSP、Norgate、EODHD、Tiingo |
| 施洛斯的市净率档 | 含退市公司的时点账面和负债。用当下的代码对照，只能覆盖大约 46% 的成分 | Compustat 一类时点财务，配上含退市的价格 |
| 港股私有化，公告后买入 | 2001–2014 年的价格、公告日和要约价。代码被新公司占用后，免费日线只剩新公司；港交所标题检索不返回已退市发行人的公告 | Webb-site 的完整导出（事件、已除牌价格、持股），或者 Wind 一类数据库 |
| 港股私有化，净现金加高控股 | 退市公司在建仓日之前已经公布的净现金和控股比例 | 同上。Webb-site 的持股导出，或者 Wind |

巴菲特那条在 2009 年以后已经能组出篮子，价格覆盖 60%。中性填法下仍然跑输，也跑输没有催化剂的对照，所以结论是放弃，不挂在这张未完成的名单上。

## 这一批留下的做法

1. **回测之前先出覆盖率表。** 港股完成案在 2014 年之前的价格覆盖是 0。分拆在免费行情里大约一半。覆盖率低于事先写的 70% 时，有价格的子集不能当作证据。
2. **留一条更笨的对照。** 施洛斯案例里，「只要求靠近三年低点、不要求从五年高点跌下来」本身就跑输标普。附加条件只是少亏一点，没有变成超额。
3. **分批买入要先配上同样多的现金再比。** 分批买的 Calmar 高出大约 0.03，同时现金从 21% 升到 37%。把一次买完的组合配上同样多的现金之后，多出来的那一截大约只剩 0.02，而且回撤并没有真的更浅。
4. **价差很宽的交易要人工核对。** 现金并购的正则，在宽价差那一截上更容易把宣布前的价格当成入场价。宽价差又正好是规则想买的那一截。核查前的表偏乐观；核查后年化大约 1%。

## 港股案例留下的单笔算法

正式结论是数据 blocker。有价格的子样本里，完成率大约 88%–90%（失败名单偏少，所以这个数偏高），完成的中位收益 +8.3%、大约 124 天，失败的中位亏损 −21.5%。已经公告的一宗，可以粗算成 **0.9 × 价差 − 0.1 × 跌回去的亏损**。这是诊断，不是通过及格线的策略。2019–2026 年那段组合诊断，去掉超额最好的三年之后也不过线。

本研究只公开过程和结论，不构成投资建议。
