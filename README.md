# value-investor-reverse-engineering

**Build in public** lab: reverse-engineer how value investors actually invest (13F + primary letters), turn that into **falsifiable rules**, then preregister → reproduce → stress-test → **abandon / forward-observe / keep**.

Inspired by [Levels’ build-in-public approach](https://www.levels.com/blog/why-levels-is-building-in-public): openness as rigor and accountability—not just marketing.

## Why public
- Preregistration lands **before** backtest numbers.
- Failures and abandons are first-class results.
- No cherry-picking only the winners.

## Scope
- Managers with public records (letters, audited returns, and/or 13F).
- Framing (Li Lu): growth and special situations are still value investing if price vs intrinsic value is the question.
- **13F alone cannot compute true net returns** (missing shorts, cash, non-US, timing). Use it for style hypotheses; prefer audited/original return tables for performance claims.

## Method
1. Translate verbal style → falsifiable rule (universe / buy / hold / sell / weight).
2. Lock scoreboard & pass bars **before** running.
3. Reproduce + fix biases (delisting, look-ahead, costs, dividends).
4. Anatomy → one-knob variants → compare to simple baselines.
5. Adversarial review → one of three outcomes only.
