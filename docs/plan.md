# 研究计划

状态：及格线在 2026-10-19 锁定。本文件是第一批动手之前的范围。后来的回测数字没有拿来改这些门槛。公开时只改了措辞：私人对照写成「作者自己的保守基准组合（不公开）」。

要回答的问题只有一句：大师说过和做过的事，能不能收成另一个人可以独立执行的买卖规则。成长股、分拆、并购价差，只要仍是付出的价格对上得到的价值，都留在范围内。分得开的是：哪一段能打分，哪一段只能留在当时的判断里。

每个案例走同一条路：先把规则写死，再写及格线，然后才看数据。结论只允许四种：放弃、前向观察、备忘录门槛、数据 blocker。放弃和数据不够都算进展。

## 及格线

相对 SPY **或**作者自己的保守基准组合（不公开）：

1. Calmar 至少高出 0.05，同时最大回撤不能再深超过 5 个百分点。
2. 去掉相对超额最好的 3 个自然年之后，Calmar 仍然更高。
3. 换成更早的起点再测一次，仍然成立。本批能用的早起点主要是 2000 年和 2008 年。数据到不了的起点，事先写明，全过时的上限也只能是前向观察。
4. 交易成本从每边 0.10% 提高到 0.30% 之后，仍然成立。

公开对照是 SPY 和标普成分等权。作者自己的组合只参加打分。成分、账户和净值序列不进仓库。可选文件是 `data/private/author_benchmark.csv`，列是 `date`, `nav`。不提供这个文件时，脚本只和公开基准比较。

港股私有化另案使用同一套数字门槛。公开基准换成盈富基金 2800.HK。主成本在那份预注册里直接定为 30bp。

以下情况不算通过：事后在一堆参数里挑一个最好看的点；超额只来自最好的一到三年；只用今天还在上市的公司做出的漂亮数字；把 13F 的季度末持仓当成可以交易的策略。

## 第一批要检验的规则

顺序是施洛斯、格林布拉特、林奇、巴菲特早年的催化剂。每一条的可执行文本以该案例的 `preregistration.md` 为准。这里只保留当时定下的形状。

| 案例 | 当时写死的形状 |
|---|---|
| 施洛斯 | 分散买入相对账面便宜、负债不高、价格靠近多年低点的股票，慢慢卖。免费数据没有含退市的全市场账面时，先不做伪回测。后来实际检验的是标普里跌下来的成分股 |
| 格林布拉特 | 只做能认出来的公司行动：分拆完成后持有，以及现金并购里价差至少 5% 的目标。魔法公式不在本批 |
| 林奇 | 只留能写成公式的一截：增长处在给定区间、PEG 小于 1、负债不高。没有带时间戳的一致预期时，用过去三年的利润增速代替，并标明这是代理 |
| 巴菲特早年 | 比净现金便宜，并且过去一年看得到回购、私有化或要约。没有催化剂的便宜股票只当对照 |

明确不写成规则、因此不进回测的部分：把很大比例的资金押进单一一家公司；用保险浮存金加杠杆并控股经营；逛商场、十倍股故事、拜访管理层之后的感觉；没有公开记录的私人交易流水；只靠 13F 季度末持仓。

## 事先知道的数据边界

理想的价格和财务是含退市的数据库。本批只用免费数据：SEC EDGAR、XBRL，以及不含退市历史的免费行情。覆盖率低于 70% 时记数据 blocker，不用有价格的子集宣布通过或失败。

港股私有化是 2026-10-20 另开的一案，用来回答「美股免费行情看不到退市和私有化时，港股公告能不能补上」。它有自己的预注册，写在出数之前。公开基准是 2800.HK。两条问题是：公告之后买入并持有到完成；净现金高并且控股股东持股高的公司，会不会更常被私有化。
